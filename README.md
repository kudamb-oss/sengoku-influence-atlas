# 戦国期・影響力アトラス研究

## 目的と現在地

戦国期日本の軍事・政治・経済・宗教・物流・人的関係などのInfluenceを、主体・時点・場所・Evidenceに結び付けて追跡する。複数レイヤーで同じ地域の異なる影響を別々に評価し、将来的に重ね合わせて分析するための研究プロジェクトである。**軍事専用ではない**。最初の研究期間は **1560～1582年**。今後のレイヤーのSchemaは未確定であり、軍事レイヤーとは別の評価軸として設計する。

現在は**1560年全国Military Influence Layer初版をFREEZE済み**。`approved=10`、`withheld=29`。原claim、Evidence、sourceへの追跡を優先し、[投影JSON](data/military_influence_1560.json)は場所IDを索引として保持する。境界・座標を持つ全国塗り分け地図ではない。空白や`withheld`は「軍事Influenceがない」「無支配」を意味しない。投影仕様と限界は[最終監査](REVIEW_MILITARY_INFLUENCE_LAYER_FREEZE_1560.md)に記す。`node build_military_influence_1560.js --check`で原本と投影の一致および参照整合性を確認できる。

この初版は旧国68件に加え、旧国体系外の琉球・蝦夷地を調査対象として明示した。代表5ケースの設計検証時点では一部記録済み15国、未調査53国だった。現在は `coverage_1560.csv` で調査段階と知識状態を別々に記録する。未調査や判定不能は「軍事主体が存在しなかった」という意味ではない。全国の勢力判定は未着手の地域を多く残す。

## 設計原則

- 最初から全国を対象にする。堅田などの最小地域を完成させてから全国へ拡張する方式は採らない。
- 初期空間解像度は旧国とする。国単位が粗すぎる箇所だけ、親地域を残して中間地域・郡・拠点へ分解する。城・港・都市・寺社も拠点にできる。
- 時間軸は1560～1582年を確保する。1560・1565・1570・1575・1580・1582年のような粗い断面から始め、変化の激しい期間は年・月・日へ細分化する。1560年の一件は「その年の少なくとも一時点」を指し、年中の継続支配を意味しない。
- 主体の影響度、確信度、研究上の知識状態、地域全体の構造を別軸にする。`unknown` は判定不能であり、史実上の分立や軍事主体の不在を意味しない。
- 一国に複数の軍事主体を記録できる。家名は `actor_group` として保持し、軍事意思決定の単位である `actor_id` と区別する。血縁だけで統合せず、従属・同盟・敵対は別の関係として記録する。
- 領有・軍事行動・進入・動員可能性は異なる判定であり、一つの「支配」へ畳まない。出典が示す範囲を越えた面塗りをしない。
- 文献の記述と本研究の推定を分ける。複数出典、異説、ページまたは該当箇所、参照日を追跡する。本文未読の検索抄録は候補化までに限り、確定・アトラス採用の根拠にしない。

## データの読み方

形式は **複数のUTF-8 CSV表**とした。`places.csv` は `parent_id` で階層を表し、国→中間地域→必要な郡→拠点へ行を追加できる。`actors.csv` は軍事主体と家名を分ける。`evidence_1560.csv` は出典が示す記述、`claims_1560.csv` は地域と主体に関する研究上の評価を表し、`claim_evidence.csv` で結ぶ。`region_structure_1560.csv` は地域全体の軍事構造を別に評価する。`claim_sources.csv` は一判定と複数文献を結ぶ。`sources.csv` は政治等の将来のレイヤーとも共用する書誌マスターである。`coverage_1560.csv` は未調査と調査済み判定不能を区別する。

CSVを選んだ理由は、今回の少量の調査台帳をGit差分と表計算で確認しやすく、外部アプリやデータベースサーバーを要さないためである。階層IDと結合表を分離しているため、郡・拠点の追加時に列や既存行を作り直さずに済む。関係や件数が増えて参照整合性の管理が難しくなった段階では、同じ表をSQLiteへ移す。スキーマと状態の意味は [データ設計](SCHEMA.md) に記す。

代表5ケースの検証で、初版の `confirmed` 3件は勢力圏ではなく出来事の確認だと分かった。これらを `evidence_1560.csv` に移し、`claims_1560.csv` を研究上のAssessmentに限定した。`atlas_status=approved` の行だけをInfluenceとして投影する。旧 `uncertain` と自由記述の影響度は新しい状態軸へ機械的に変換せず、候補記録として保持した。大隅追加ケースでは旧国境の確認を行い、菱刈院を大隅国へ、志布志城周辺を日向国へ置いた。

## 既存研究との関係

別研究の`katata-1570`から、史料の陳述・研究者の解釈・研究仮説を分ける方法、出典ID、未確認を可視化する方法を引き継いだ。堅田の1570年の出来事を1560年の近江へ転用していない。堅田の小事例を全国モデルの基礎にする従来の作業順も継承しない。この独立リポジトリには`katata-1570`のファイルを含めない。
